Tento projekt s názvom Dungeon Escape bol vytvorený ako súčasť bakalárskej práce. Ide o 2D hru vyvinutú v Unity.

Hráč sa pohybuje v prostredí, zbiera objekty a snaží sa dosiahnuť cieľ bez odhalenia nepriateľmi. Hra obsahuje systém dynamickej úpravy obtiažnosti (DDA), ktorý sa prispôsobuje správaniu hráča.

Vybuildovanú verziu hry si môžete stiahnuť tu:

Po stiahnutí stačí rozbaliť .zip a spustiť .exe súbor.
